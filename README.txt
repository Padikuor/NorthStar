NorthStar: career coaching for Bay Area high schoolers
======================================================

HOW TO PUBLISH
- Netlify: go to app.netlify.com/drop and drag this whole "northstar" folder
  (or the zip) onto the page. Done.
- Vercel, GitHub Pages, Cloudflare Pages, or any web host: upload the contents
  of this folder so index.html sits at the top level.

WHAT'S INSIDE
- index.html   the whole site (styles, code, data and Ida's photo are built in)
- thumbs/      video thumbnail images used on the "Watch a day in the life" pages

GOOD TO KNOW ON A NORMAL WEBSITE
- Everything else works: the assessment, all 1,016 careers, roadmaps, videos,
  the Share page (Save as PDF, Copy as image, Open email), and light/dark mode.
- Mentor sign-ups ("Shadow a pro") are saved in each visitor's own browser only.
  To share them with everyone, connect a database (for example Supabase or
  Firebase). The three sample mentors show by default.
- Ida answers the quick questions. The "type any question" chat box only
  appears inside Claude, because it uses Claude to answer.
